# MINDFORGE — 스스로 게임을 배우는 봇 엔진

REDSHIFT 에 처음 들어간 공용 학습 엔진이에요. 게임 규칙을 몰라도 되고(미분 불필요),
**관찰 → 행동 → 점수** 세 가지만 정해 주면 어떤 게임이든 같은 방식으로 학습시킬 수 있어요.

```
src/ai/nn.js      신경망(Policy): 관찰 정규화 + MLP, JSON 저장/불러오기
src/ai/es.js      진화 전략(ES) 학습기 + 시드 고정 난수 + Elo
tools/train/      브라우저 여러 개로 수천 판을 돌리는 오프라인 학습기 (Python)
```

## 학습 순서 (REDSHIFT 기준)

1. **모방 학습** — 기존 규칙 봇(최강)이 싸우는 걸 1초에 20번 기록해서
   "이 상황(관찰)에서 이렇게 했다(행동)" 를 신경망에 옮겨 담아요. (`tools/train/imitate.py`)
2. **자가대전 진화 학습** — 두뇌를 조금씩 흔든 후보 수십 개를 같은 경기 조건으로 싸우게 하고,
   이긴 쪽으로 두뇌를 옮겨요. 상대는 최강 봇 · 어려움 봇 · 과거의 나(리그). (`tools/train/train.py`)
3. **게임 안 이어서 학습** — AI 훈련소에서 같은 알고리즘이 브라우저에서 계속 돌아가요.

## 새 게임에 붙이는 법

게임 쪽에 세 가지만 만들면 돼요.

| 만들 것 | 내용 | REDSHIFT 예시 |
|---|---|---|
| `observe(봇, out)` | 봇이 보는 것을 숫자 배열로 | 내 체력·속도, 적까지 거리·방향, 원반 상태, 벽까지 거리 8방향… (67개) |
| 행동 해석 | 신경망 출력 → 실제 입력 | 이동 2 · 점프 · 대시 · 던지기 · 던지기 방식 3 · 조준 보정 2 · 회수 · 순간이동 · 스킬 (15개) |
| 경기 점수 | 한 판이 끝났을 때 얼마나 잘했나 | (준 피해 − 받은 피해) + 60 × (킬 − 데스) |

그리고 헤드리스로 한 판을 빨리 돌리는 함수 하나(`evalMatch`) — 렌더링 없이 물리 틱만 돌리면
실제 시간보다 수백 배 빨라요. 나머지(신경망, 학습기, 저장, 리그)는 그대로 가져다 쓰면 돼요.

```js
import { Policy } from './ai/nn.js';
import { ES } from './ai/es.js';

const pol = new Policy([OBS, 64, 48, ACT]); pol.net.init();
const es = new ES(pol.net.p, { pop: 16 });
for (;;) {
  const cands = es.ask();
  const fit = cands.map(c => { const p = pol.clone(); p.net.p.set(c.params); return playMatch(p); });
  es.tell(fit);
}
```

### 잘 배우게 하는 요령
- **사람급 몸 + 학습된 판단**: 조준 속도·반응 시간 같은 "몸" 은 사람 수준으로 고정하고, 판단만 배우게 하면
  사기 같지 않으면서 강해요. (REDSHIFT 의 학습 AI 가 이 방식)
- 처음부터 무작위로 시작하지 말고 **기존 봇을 먼저 따라 배우게(모방)** 하면 학습 시간이 수십 배 줄어요.
- 같은 세대의 후보들은 **같은 시드(같은 맵·무기·난수)** 로 싸우게 해야 공정하게 비교돼요.
- 상대를 하나로 고정하면 그 상대만 이기는 꼼수를 배워요 → 여러 상대 + 과거의 나를 섞기.
